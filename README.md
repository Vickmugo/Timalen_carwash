# Timalen_carwash
Booking and product-quote demo for a combined car wash + concrete products business (Next.js, mock data, no live payment yet)
Prototype website for a client business that runs a car wash and a concrete products line (cabros, fencing posts, decorations) from one premise. Two flows: book a wash slot, or buy standard products / request a quote for custom or bulk orders. Built with Next.js, TypeScript, and Tailwind. Uses local mock data, not a database — payment is stubbed, not connected to a real processor — and the admin view has no auth yet. Not ready to deploy.
